# Vous êtes fils d’enseignant(e) et vous postulez à une bourse ou un prêt ?

Les dossiers de candidature à une bourse ou à un prêt tels que négociés avec les différents syndicats selon des conventions signées en la matière, sont étudiés dans le cadre de commissions appropriées puis envoyés à l'OOUN.
Les résultats du travail de ces commissions sont annoncés sur le site web de l'OOUN [www.ooun.rnu.tn](http://www.ooun.rnu.tn)
Les documents exigés sont les mêmes que pour les nouveaux bacheliers, les bourses en cours d'études ou les bourses de mastère.
