# Etapes et délais des prêts

1- Envoi du dossier à l'office concerné
2- Etude des dossiers
3- Retrait des contrats pour les dossiers retenus (à travers le site web) au cours des mois d'Octobre, Novembre et Décembre.
4- Retour des contrats dument signés
5-Payement des prêts par le biais des bons de caisse auprès des bureaux de recette des finances

| Montants des prêts par type | |
| Type | Montant |
| Les 3 premières années | 600 DT |
| Les 3 secondes années | 800 DT |
| 1ère année mastère | 1000 DT |
| 2 ème année mastère | 1400 DT |

Les prêts sont payés en une seule fois
